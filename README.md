# homebrew-flute-cli-v2-mcp

Homebrew tap for [flute2-mcp](https://github.com/getflute/flute-cli-v2-mcp).
Formulae here are published automatically by cargo-dist on each release.

```sh
brew install getflute/flute-cli-v2-mcp/flute2-mcp
```

`flute2-mcp` is an MCP server that drives the `flute2` payments CLI, so it
also needs [flute2](https://github.com/getflute/flute-cli-v2) **v1.1.0 or
newer** installed:

```sh
brew install getflute/flute-cli-v2/flute2
```
